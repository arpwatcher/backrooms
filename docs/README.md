# NOCLIP ∞ - game design document

This is the design for NOCLIP ∞, a co-op horror game for one to four players
set in the Backrooms. The browser build in this repository puts it into
practice one piece at a time. When the design and the code disagree, the
document is the target and the code is where things currently stand.

| # | Document | What it covers |
|---|----------|----------------|
| 1 | [Pitch and pillars](01-pitch-and-pillars.md) | what the game is, and the rules every decision is checked against |
| 2 | [Core loop and co-op](02-core-loop-and-coop.md) | a level from entering to leaving, and how four people play it together |
| 3 | [Lucidity, death and items](03-lucidity-death-items.md) | the meters, how you die, Echo deaths, what you carry |
| 4 | [Entities: twenty in full](04-entities.md) | each entity's tell, rule, counter, co-op twist and pairs |
| 5 | [Level generation and archetypes](05-levels.md) | how a level is made, twenty archetypes in full and forty more |
| 6 | [Rule shifts](06-rule-shifts.md) | forty-two ways a level can change the rules |
| 7 | [Tasks](07-tasks.md) | forty things a level can ask of you before it lets you leave |
| 8 | [The famous ones, and homages](08-famous-entities.md) | thirty-two from Backrooms folklore and twelve homages with original names |
| 9 | [The threat director and synergies](09-director.md) | budgets, debuts, variety, tension and mercy; thirty-two pairings |
| 10 | [The entity generator](10-entity-generator.md) | tables that make new entities, and thirty samples |

Status markers used throughout: **[built]** means it is in the browser build,
**[next]** means it is planned for the next few sessions, and **[later]** means
it is designed but further out.
