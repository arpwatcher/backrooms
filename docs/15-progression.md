# 15. Progression

NOCLIP ∞ has no experience points and no unlock trees. You progress in two
ways: you know more, and you get deeper.

## What carries over between runs

| What | Where | Status |
|------|-------|--------|
| **The codex**: every entity you've survived, in full; the rest only by their tell | this browser (`localStorage`) | built |
| **Your deepest level** per tier | this browser | next |
| **Seeds you liked**, to replay or share | URL `?seed=` | built (URL); a saved list is later |
| **Settings** (sensitivity, volume) | this browser | built |

What does **not** carry over: items, batteries and marks. Every run starts
with an empty hand, so knowledge is the only thing you keep.

## Within a run

- **Depth** is the score.
- **Checkpoints** every 5 levels. Dying wakes you at the last one with the
  same seed, so the same levels and the same lessons are waiting.
- **Inventory** is small: almond water, the flashlight's battery, and later
  four item slots (§3).
- **Marks** reset each level. An entity that touched you on level 6 has
  forgotten you on level 7.

## Milestones [next]

Shown on the title screen, quietly, as lines in a list rather than
achievements with sound effects:

- *survived your first contact*
- *finished level 9 without being touched*
- *met every entity*
- *reached level 25*
- *restored power with a Smiler on the level*
- *walked past a party*
- *completed a silent level* (you'll only find out afterward that it was
  one)

## The long tail [later]

- **Variants unlock by familiarity**: survive a famous entity 5 times and
  its variant (Red Smiler, Alpha Hound) starts appearing.
- **Generated entities from depth 15**: the codex keeps growing without a
  ceiling.
- **Daily seed**: everyone plays the same run that day, with a shared
  depth table.
- **Notes from other players** (opt-in): the "leave a note" task writes into
  other people's runs.
